# cdb-hub-docs

This repository is the GitHub Pages publish target for CDB Hub guides.

Guides are written in the private `cdb-hub` repository under `docs/`. This repository is not a third product, and it is not where guides are edited. The `gh-pages` branch receives the built HTML and the proprietary documentation license. The published site is [https://data-biz-ai-consultancy.github.io/cdb-hub-docs/](https://data-biz-ai-consultancy.github.io/cdb-hub-docs/).

The documentation license is proprietary. It is not the MIT license used by [cdb](https://github.com/data-biz-ai-consultancy/cdb).
